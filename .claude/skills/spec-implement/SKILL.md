name: spec-implement
description: Implement an approved spec from the /specs directory, building to its acceptance criteria.
---

Implement the spec for $ARGUMENTS. Find the matching spec file under the /specs directory and build to it exactly — do not improvise design decisions the spec did not make.

Work in this order: read the spec, confirm it is signed off, touch only the files listed under "Files to Modify" (surface it first if a file outside that list must change), then verify every item under "Acceptance Criteria" and "Test Plan" before reporting done.

For the implementation checklist, see [checklist.md](checklist.md)
