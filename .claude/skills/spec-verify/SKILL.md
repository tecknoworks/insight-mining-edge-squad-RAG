---

You need to exam the prd file (docs/prd/<prd-file>.md) to understand the product requirement and then exam the files modified by the spec file (specs/<spec-file>.md) to see if it implemented the correct thing.

Make sure to perform an integration test by running the project and test the implementation thoroughly.

As a result, you must create a comprehensive step-by-step plan to fix everything that's not correct with the initial implementation highlighting the issues found.
